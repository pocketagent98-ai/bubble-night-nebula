# Bubble Night: Nebula

A 3D constellation map, a synthesised sound bank, ten earned boosters and a
daily reward layer, on top of [Bubble Night](https://github.com/SyscallBrain/bubble-night) —
the offline, ad-free Android bubble shooter with 600 certified levels.

**This repository is an overlay, not a fork.** Upstream ships 600 levels, 1,800
solution certificates and a solver in 2,600 files. Copying all of that here would
just let it drift, so this repo carries only the Nebula layer: new source files,
whole-file rewrites, and six exact text edits to three upstream files.

## Get a complete, buildable project

```bash
git clone https://github.com/SyscallBrain/bubble-night bubble-night
git clone https://github.com/pocketagent98-ai/bubble-night-nebula nebula
python3 nebula/apply_overlay.py bubble-night          # checks every anchor first
cd bubble-night
python3 tools/gen_audio.py                            # 29 sound effects, ~2 s
python3 tools/gen_sprites.py                          # 32 sprites, ~25 s
python3 tools/verify_build.py                         # 6 checks, ~2 s
./gradlew :app:assembleDebug                          # needs a JDK 17 + Android SDK
```

`apply_overlay.py` verifies that each anchor occurs exactly once before it writes
anything, so a moved line fails loudly instead of producing a half-wired build.
Add `--check` to test without writing.

## Or just run the notebook

`overlay/notebooks/BubbleNight_Nebula_Studio.ipynb` does all of the above on Google
Colab and drops the finished zip in `MyDrive/BubbleNightNebula/`. Open it, run the
cells, about three minutes, CPU only.

## Design notes

**No new permissions.** The manifest is untouched. Still no `INTERNET`, no ads,
no accounts, no analytics.

**No third-party assets.** Every sprite and every sound is generated by the two
Python scripts. The art is reproducible and diffable, and there is no licence
question.

**No profile migration.** The daily streak lives in its own `SharedPreferences`
file rather than in `Profile`, so the campaign save format, its checksums and its
backup/recovery path are untouched. Existing saves keep working and the 1,800
certified solutions still verify.

**Nothing is purchasable.** Boosters unlock by reaching an orbit or holding a
streak. That is the "earned, not sold" reading of what the reference games do —
and the largest one's top review complaint is an ad appearing at the end of a level.
